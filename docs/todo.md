# Задачи Nether Earth Reloaded

Контрибьютор: vibic777  
Дата: 2026-10-12

Карта-прототип — длинный прямоугольник 48×14. Нейтральные дома, камни, деревья, вода и горы остаются препятствиями и не захватываются.

## Сделано

- [x] Godot 4.7, GDScript, сборка Windows / Linux / Android (`docs/deploy.md`).
- [x] Изометрия на четыре ракурса, зум, нормализация масштаба, сдвиг карты.
- [x] Проходимость шести классов и инженера.
- [x] Связь от штаба и вышек: вне круга юнит замирает.
- [x] Захват плиты инженером, 8 секунд, сирена.
- [x] Выбор оружия и силы I–III. Бомбы только у БПЛА и ротора.
- [x] Общий склад: металл, чипы, энергия. Заводы по профилю, очередь постройки.
- [x] Стрельба выбранным комплектом: пули, снаряды, огнемёт, ракеты, бомбы, лазер, плазма, ионный стан, цепь теслы.
- [x] Запас прочности машин и разрушение. Попадание по инженеру срывает взлом.
- [x] ИИ и три сложности: рейды, охота на инженеров, перерезка вышек.
- [x] Победа и поражение: захват или разрушение штаба.
- [x] Приказы марш, захват и охрана. Флаги ставятся и снимаются, охрана держит метку или объект.
- [x] Рамка выделения, стрелка под команду и группы Ctrl+0–9, роспуск группы.
- [x] Нижняя панель: миникарта (ЛКМ/перетаскивание камера, ПКМ приказ), состав, слот сюжета.
- [x] Сплошной рельеф без швов клеток; наклон наземной техники по склону.
- [x] Процедурный арт окружения, узлов и техники (`docs/ART.md`).
- [x] Тестовая Windows-сборка `build/windows/NetherEarthReloaded.exe` (headless-тесты OK).

- [x] Схватка до 8 сторон: лобби, слоты человек/ИИ/закрыт, команды, цвета, старты.
- [x] Карты 2/4/6/8 в data/maps (симметричные, свой цех у каждого старта).
- [x] ИИ на каждую сторону, 5 уровней (Новичок…Эксперт), постройка с лимитом.
- [x] Сеть LAN: сервер, поиск игр (UDP), вход по IP, хост-авторитет, ИИ вместо ушедшего, tools/firewall.ps1.
- [x] Штурмовик: пушка по воздуху, ракеты, управляемые бомбы, боезапас и перевооружение.
- [x] Переименование в Nether Earth Reloaded, README о самостоятельности проекта.
