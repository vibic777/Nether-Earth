# Карты схватки: data/maps/<id>.json

Список карт в лобби задаёт `data/game.json → skirmish.maps`. Игра ищет файл в таком порядке: `data/maps` рядом с exe → `user://maps` → встроенный.
Симметричные карты строит `python3 tools/gen_maps.py`. После генерации их можно править руками.

| поле | смысл |
|---|---|
| id, name, description | идентификатор, название, описание в лобби |
| players | число стартов (2/4/6/8) |
| symmetry | группа симметрии: `r2` (поворот 180°), `c4` (повороты 90°), `d2` (две оси), `d4` (квадрат) |
| width, height | размер в клетках |
| rows | строки клеток: `.` равнина, `s` камни, `t` деревья, `w` вода, `m` гора, `b` здание |
| starts[] | `index`, `title`, `hq` (клетки штаба), `terminal` (плита перед штабом), `radius` (связь), `metal/chips/power` (доход), `roster` (необязательно: `[["WALKER", x, y], ...]`; без него — `skirmish.start_roster` вокруг штаба) |
| sites[] | нейтральные узлы: `kind` (HQ/RELAY/FACTORY/EXTRACTOR/AIR/ROBOT), `title`, `cells`, `terminal`, `radius`, `metal/chips/power`; `start: N` — узел с начала принадлежит стороне старта N |

Карты в комплекте: Классика (2, исходная, несимметричная), Дуэль (2, r2), Перекрёсток (4, c4), Шестеро (6, d2), Восьмёрка (8, d4).
У каждого старта на симметричных картах есть свои штаб, цех, жила и вышка.

Старты, которые никому не назначены в лобби, остаются пустыми: штаба там нет, цех нейтрален.
Проверка: тест `_check_skirmish` проверяет число стартов и то, что терминалы стоят на равнине. `tools/sim.gd` прогоняет бой ИИ без экрана.
